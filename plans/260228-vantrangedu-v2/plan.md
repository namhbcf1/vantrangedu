# Plan Tái Thiết Vân Trang Edu v2.0 (Phiên bản 2026)

## Overview
- **Dự án**: Vân Trang Edu - EdTech Platform
- **Mục tiêu**: Xây dựng lại hoàn toàn từ đầu (từ số 0) với kiến trúc Next.js 15 App Router, cơ sở dữ liệu D1 + Drizzle ORM, và host 100% Free trên Cloudflare Pages/Workers.
- **Tính năng nổi bật**: Adaptive UI (Giao diện Mobile/PC riêng biệt cắt rẽ từ component), Auto-save bài thi, Hệ sinh thái bảo mật tân tiến bằng Better-Auth.
